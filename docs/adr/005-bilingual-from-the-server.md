# ADR-005: ثنائية اللغة تبدأ من الخادم لا من الواجهة

- الحالة: مقبول
- التاريخ: 2026-08-29
- المرحلة: 1

## السياق
لغة المنصة العربية مع إمكانية التبديل للإنجليزية. الرسائل التي يراها المستخدم
لا تُولَّد كلها في الواجهة: قوالب واتساب وإشعارات FCM ورسائل الأخطاء تأتي من
الخادم.

## القرار
1. `LANGUAGE_CODE = "ar"` و`LANGUAGES = [ar, en]` مع `LocaleMiddleware`.
2. حقل `preferred_language` على `Creator` و`AccountOwner`.
3. `MessageTemplate` مفتاحه `(key, channel, language)` — نسخة لكل لغة.
4. نصوص الواجهات العربية هي الأصل، والإنجليزية ترجمة مطابقة.

## الأثر
إضافة لغة ثالثة لاحقًا = صفوف قوالب جديدة وملف ترجمة، دون تعديل جداول.
