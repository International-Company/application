# ADR-002: آلة الحالات هي المسار الوحيد لتغيير حالة طلب السحب

- الحالة: مقبول
- التاريخ: 2026-08-29
- المرحلة: 1

## السياق
القاعدة المالية الحاكمة: الانتقال إلى `received_eg` وحده يُنشئ قيدًا دائنًا لرصيد
المبدع. أي مسار بديل لتغيير الحالة يفتح ثغرة دفع بلا مال واصل.

## القرار
1. جدول `ALLOWED` يحدد الانتقالات المسموحة، وما ليس فيه مرفوض.
2. `state_machine.transition()` هي الدالة الوحيدة التي تُغيّر الحالة، وتتولى:
   قفل الصف (`select_for_update`)، ختم الوقت، القيد المحاسبي عند `received_eg`،
   وكتابة سجل التدقيق.
3. `WithdrawalRequest.save()` يرفض أي تغيير حالة لم يأتِ عبر آلة الحالات.
4. `received_eg` يقيّد المبلغ **الواصل فعلًا** لا المبلغ المتوقع.

## الأثر
كل انتقال موثّق في `audit_log`. تغيير آلة الحالات يتطلب موافقة صريحة وفق
قواعد المشروع.
