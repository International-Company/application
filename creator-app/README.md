# تطبيق المبدع

Kotlin + Jetpack Compose. الواجهة الوحيدة للمبدع: عربية، خط كبير، تباين عالٍ،
خلفية بيضاء، و**لا حقل نصي واحد في التطبيق كله**.

## المبدأ الحاكم: الأزرار إرشادية بحتة

لا يوجد في هذا التطبيق أي أتمتة داخل TikTok:

- **لا** خدمة إتاحة (Accessibility Service)
- **لا** حقن أحداث لمس
- **لا** نقر آلي ولا قراءة شاشة

الزر يفتح TikTok ويعرض بطاقة الخطوات، ثم يتوقف دوره. المبدع يضغط بإصبعه دائمًا.
بطاقة الإرشاد نفسها لا تلتقط اللمس (`FLAG_NOT_FOCUSABLE`) فكل ضغطة تمر إلى TikTok تحتها.

## البنية

| الوحدة | الملف | ما تفعله |
|---|---|---|
| الربط | `auth/TikTokLogin.kt` | واجهة Login Kit + PKCE. **SDK غير مربوط بعد** |
| الهاتف | `auth/PhoneVerification.kt` | Phone Number Hint + SMS Retriever — بلا إذن قراءة رسائل |
| السلامة | `auth/DeviceIntegrity.kt` | Play Integrity؛ التحقق على الخادم لا الجهاز |
| التعبئة | `autofill/Mobde3AutofillService.kt` | تعبئة داخل TikTok وحده |
| الإرشاد | `overlay/GuideOverlayService.kt` | بطاقة نصية فوق TikTok |
| الالتقاط | `notifications/TikTokNotificationListener.kt` | إشعارات TikTok الموثّقة بتوقيعها |
| الإشعارات | `notifications/CreatorMessagingService.kt` | FCM |

## رحلة الضغطات

**مرة واحدة:** ابدأ ← سماح (TikTok) ← تفعيل ← إذنان من النظام ← جهّز ← لمس الخانة
← تعبئة تلقائية ← حفظ ← عودة.

**كل سحب: ٣ ضغطات.** «سحب» عندنا، ثم «سحب» و«تأكيد» داخل TikTok.

## البناء

```bash
./gradlew :app:assembleDebug -PapiBaseUrl=http://10.0.2.2:8000
```

`10.0.2.2` هو عنوان جهازك من داخل محاكي أندرويد.

للإنتاج تُمرَّر أيضًا بصمات توقيع TikTok بعد رصدها:

```bash
./gradlew :app:assembleRelease \
  -PapiBaseUrl=https://api.example.com \
  -PtiktokSignatures=AA:BB:CC...
```

## ⚠️ ما لم يُنجَز ولماذا

| البند | الحالة | السبب |
|---|---|---|
| **TikTok Login Kit** | خلف واجهة، غير مربوط | يتطلب اعتماد التطبيق لدى TikTok وتسجيل بصمة توقيعه. لم يُخترع له أي استدعاء |
| **بصمات توقيع TikTok** | فارغة | لم تُرصد على جهاز حقيقي. **يفشل مغلقًا**: بلا بصمات يُعتبر كل إشعار غير موثوق |
| **نصوص إشعارات TikTok** | أنماط عامة | النص الحرفي مجهول (§16). ما لا يُفهم لا يُرسل |
| **رابط شاشة الرصيد** | غير موجود | لا رابط داخلي موثّق. يُفتح التطبيق والبطاقة تقود |
| **google-services.json** | غير مرفوع | يُضاف من مشروع Firebase الخاص بك |
| **البناء والتشغيل** | لم يحدث | لا توجد أدوات Android SDK على جهاز التطوير |

**هذه المرحلة هي الوحيدة التي لا تُغلق إلا على جهاز حقيقي.** ما يلزم رصده:
نص إشعار TikTok عند طلب السحب وإتمامه ورفضه، وبصمة توقيع حزمته، وهل تقبل خانات
وسيلة الدفع التعبئة التلقائية أم يلزم لوحة مفاتيح.
